01 / The approach

Check claims before verbs.

E-Prime means English without grammatical forms of to be: be, am, is, are, was, were, been, being, including their contractions. That constraint invites writers to name actions, observations, and perspectives rather than rely on broad declarations.

This skill pairs that writing constraint with evidence-scoped claims and protection for exact technical literals. Use it for code reviews, status updates, incident reports, and explanations—not to restyle source code.

A broad claim

“The fix is correct.”

A bounded observation

“test_refresh_token passed; integration tests have not run.”

Illustrative rewrite, assuming that evidence. Never invent a test result to make a sentence sound more precise.

01

Name the observation.

Say which request failed, which test passed, or who reported the behavior. Avoid turning one observation into a universal claim.

02

Keep the boundary.

Distinguish evidence from inference. Name what remains unchecked instead of letting confident wording hide uncertainty.

03

Preserve the literal.

Leave code, commands, API names, quotations, and diagnostics untouched—even Error: token is expired.

02 / Installation

Your agent. One small skill.

Choose one route per host to avoid duplicate discovery. Installation makes the skill available; explicit invocation or active instructions determine when it applies. No CLI, telemetry, or model service ships with the skill.

Claude Code · repository marketplace

Install directly from GitHub, without npm:

claude plugin marketplace add jwmarshall/e-prime
claude plugin install e-prime@jwmarshall-e-prime

Start a new Claude Code session and invoke /e-prime:e-prime. For a single task, explicitly add “for this task only.”

This repository marketplace does not imply approval or a listing in an official directory.

Cursor, Codex, or Claude Code · standalone skill

Clone the repository; no npm publication required:

git clone https://github.com/jwmarshall/e-prime.git
cd e-prime

Copy the complete skills/e-prime/ folder into your target project at the destination below. Keep references/ beside SKILL.md; review existing files before replacing them.

Pi or omp · local checkout or npm

Clone the repository and register its absolute path with one host:

git clone https://github.com/jwmarshall/e-prime.git
# Choose one; replace the path with your checkout:
pi install /absolute/path/to/e-prime
omp plugin install /absolute/path/to/e-prime

After npm publication, these commands provide an alternative:

# Pi
pi install npm:@jwmarshall/e-prime
# Or omp
omp plugin install @jwmarshall/e-prime

Start a fresh session and invoke /skill:e-prime. Add --local to the Pi install command for project scope.

03 / In practice

A writing discipline, not a truth detector.

Expect scoped communication.

While active, the skill guides original English in updates, explanations, reviews, and final answers. Meaning, safety, and exact requirements take priority over style.

Keep control of the scope.

Ask for one task or a session. An unscoped invocation requests the current session, subject to context retention. Installation alone does not enable standing use.

Review consequential output.

Grammar cannot establish truth or improve reasoning by itself. Model trials have shown altered identifiers and omitted evidence limits despite the policy.

Try a bounded request

After invoking the skill, give it facts and a clear scope:

Apply E-Prime for this task only.
Write a two-sentence status update.
Evidence: test_refresh_token passed; no integration tests ran.
Preserve the identifier test_refresh_token exactly.

Look for both the passing test and the untested integration boundary. Check the identifier character for character. Do not accept a new claim of overall correctness.

Pause it whenever you need to.

Say “Suspend E-Prime for this reply,” “Turn E-Prime off for the rest of this session,” or “Resume E-Prime.” For durable opt-out, remove any standing instruction you added to your host’s configuration.

Conversation controls do not edit configuration. Context compaction can lose activation state; subagents need their own loaded or explicitly supplied policy. Package checks prove file integrity and installability, not reliable model compliance or support for every host.
